FSD 頁面的「座標Y軸偏移」支援手動設定（−15 至 +15 米）及深宮自動設定。
自動設定預設關閉；啟用後，普通樓層設為 −7，Boss、結果樓層及離開深宮時設為 0。
可選擇「在隊伍內不自動偏移」：深宮自動設定啟用時，小隊人數大於 1 的自動偏移值為 0。請同時只啟用一個插件的 Y 軸偏移，以免偏移疊加。
偏移值非零時，角色頭頂會顯示 `Y offset` 與偏移米數；關閉設定視窗後仍會顯示。偏移值為 0 時隱藏。
